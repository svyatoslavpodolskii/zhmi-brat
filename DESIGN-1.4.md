# ЖМИ, БРАТ — проход 1.4

Задача: дневник на первом плане; напарник живёт рядом с тренировкой и отдыхает вместе с пользователем. Формулы, выбор упражнений и модель синхронизации сохраняются.

Палитра: бумага #ffffff / #1b2b3a; фон #f0f4f6 / #101b26; текст #163347 / #e1ebf3; синий #315bdb / #9ab6ff; успешная связь #25785c / #8fd3b6. Nunito остаётся единственным шрифтом интерфейса.

Композиция: на ПК справа один крупный напарник над компактным таймером. На телефоне он остаётся после тренировки; внутри открытого отдыха появляется крупная сцена без вложенной карточки. Тело выступает над карточкой, ноги полностью видимы. Внутренние зоны упражнений используют один фон поверхности в обеих темах.

Состояния напарника: бодрый, отдых, пауза таймера, близкое окончание отдыха. Поза задаётся отдельным слоем, краткая реакция — вложенным слоем. Нажатия не могут сбросить позу отдыха. В каждом действии несколько движений и независимый набор реплик; последняя реплика сохраняется при перерисовке. Завершённые тренировки меняют варианты разминки без искажения реальных результатов.

Сценарии: приглашение → понятный выбор входа; отказ → явное объяснение своей комнаты; связь → короткий значок в шапке, подробности по нажатию; первая встреча с новым составом → одно полноэкранное приветствие, без повторов на heartbeat и коротком переподключении.

Визуальная проверка: семь основных страниц и шесть окон, светлая/тёмная темы, телефон/ПК. Отдельно — узкий телефон, отдых, реакции лёжа, приглашение по ссылке и реальное подключение двух участников.

По результатам прохода: снято 100 исходных экранов, включая 12 дополнительных состояний. Сняты прямоугольные заливки внутренних зон упражнений; исправлен приоритет темы. Напарник использует исходный альфа-канал без multiply и прозрачности. Поза и жест разделены на два слоя, поэтому диван не может перекрыть тело или оставить стоящую фигуру поверх себя. На телефонной неделе восстановления тоже есть лежащий напарник. Таймер доступен плавающей кнопкой и на ПК при прокрутке длинной тренировки.

Проверены три варианта каждого действия и 100 реплик, смена реплик при повторных паузах, отсутствие повторного приветствия состава, вход по приглашению после отказа без перезагрузки. Проверки формул, календаря, разных устройств и обновления прошли без расхождений.
