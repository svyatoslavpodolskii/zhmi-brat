# ЖМИ, БРАТ 💪

[Открыть дневник](https://svyatoslavpodolskii.github.io/zhmi-brat/)

Дневник по «Умной Проге v 8.0 (RPE)»: упражнения на выбор, две подготовительные недели, тестовая неделя, три мезоцикла, повторяющиеся циклы, RPE, шесть калькуляторов проходки, техника и комнаты по эмодзи-коду.

## Запуск

Node.js 20 или новее. Установка зависимостей для приложения не нужна.

```sh
npm start
npm test
```

Открыть `http://localhost:4186`. Статическая версия целиком лежит в `dist/` и совместима с GitHub Pages. После первого открытия приложение работает офлайн. Для WebRTC и подписи в production требуется HTTPS.

## Комнаты

PeerJS 1.5.5 и WebRTC. Случайный код из десяти эмодзи, передаваемый в URL-фрагменте, определяет комнату. Для первой встречи участники открывают её одновременно. Результаты хранятся локально, подписываются ECDSA P-256 и сверяются по версиям. Собственный дневник редактируется, чужие доступны для просмотра. Закрытые устройства не принимают обновления. Сервер PeerJS используется для сигнализации; успешность прямого соединения зависит от сети.

В настройках профиля доступны резервная копия JSON и восстановление с добавлением циклов. Личный ключ подписи в резервную копию не включается. На другом устройстве импортированные циклы принадлежат его локальной личности.

В чужом дневнике кнопка «Взять упражнения» переносит только выбор упражнений. По умолчанию создаётся новый цикл с твоими шагами округления и пустыми результатами. Для пустого текущего цикла доступен перенос прямо в него. Чужие веса, RPE и история не копируются.

## Один профиль на телефоне и ПК

На дополнительном устройстве открой приглашение в комнату, выбери «Мой существующий профиль», затем себя в списке. Сверь проверочный код на двух устройствах. На активном устройстве подтверди запрос, затем заверши вход на новом. Привязка хранится для этой комнаты.

Каждое устройство имеет собственный ключ ECDSA. Подписанное разрешение связывает его с участником; приватные ключи не передаются. В комнате это один участник с общей историей. Одновременные изменения в разных полях объединяются, включая офлайн-записи. При изменении одного поля побеждает более поздняя версия; удаления передаются как отдельные отметки.

Если свои устройства потеряны, восстановление может подтвердить знакомый участник, чей идентификатор уже находился в подписанном списке доверия владельца. Новый случайный посетитель не получает это право только от знания кода комнаты. Настройка восстановления находится в «Мои устройства». Для восстановления нужна сохранившаяся копия дневника у участника; если потеряны все копии, потребуется резервная копия JSON.

## Обновления и округление

Новые версии проверяются при возвращении в приложение, появлении интернета и каждые 30 секунд в открытой вкладке. Доступное обновление показывает кнопку «Обновиться». Установка начинается после нажатия, с сохранением дневника. Service Worker предварительно загружает новую версию и удаляет старый кэш после активации.

Шаг округления виден и редактируется в каждой карточке упражнения, без открытия настроек. Рабочие веса пересчитываются сразу. Для упражнений со своим весом подпись переключается на прибавку повторений согласно оригиналу.

## Календарь и график работы

В календаре видны планы всех участников комнаты: каждый отмечен своим эмодзи. Если на дату отметились все участники, день становится зелёным и получает галочку. Один человек может пользоваться календарём самостоятельно.

Тап отмечает день в выбранном режиме: план, выполнено, работа или просмотр. Зажатие на 550 мс переключает рабочий день; движение пальца отменяет зажатие, чтобы календарь можно было прокручивать. Есть и обычный режим «Работа» для мыши и клавиатуры.

Графики: сутки через трое, 5/2 по будням, циклический 5/2, 4/2, 2/2, 3/3, 6/1 и свой вариант. Для циклического графика указывается первый рабочий день круга. В суточном графике отмечается дата начала смены. Ручные исключения сохраняются поверх автоматического графика. Подсчёт рабочих, выходных, запланированных и выполненных дней идёт по текущему месяцу.

Завершённые тренировки программы появляются в календаре автоматически. Ручная отметка «Сделано» обозначает день в календаре и не подставляет фиктивные веса или подходы в программу. Планы, рабочий график и исключения синхронизируются между привязанными устройствами и сохраняются в резервной копии.

## Живой напарник

Качок постоянно дышит и двигается. Во время запущенного или приостановленного таймера напарник внутри таймера анимированно отдыхает на диване. Нижний напарник отдыхает по собственной кнопке дивана или на неделе восстановления. Есть тап, зажатие, пять, бицепс, банан и расширенный набор реплик, включая «Ну что, по подходику?». Плавающие эмодзи возле персонажа убраны.

Три быстрых нажатия одной реакции (паузы меньше 1,5 секунды) запускают дождь из выбранных эмодзи у подключённых участников комнаты. Нажатия разных участников тоже складываются. Правило одинаково для всех шести реакций; одиночная реакция показывает один эмодзи. Завершение тренировки отмечается дождём 💪, окончание отдыха — 🔥. Учитывается системная настройка уменьшения движения.

Светлая и тёмная темы переключаются кнопкой в шапке. Выбор сохраняется на текущем устройстве; при первом входе используется системная тема. Тема применяется до отрисовки приложения. В профиле оставлен один список аватаров.

Разминка стоит до упражнений, округление — до полей подходов. Мобильная версия использует фирменный логотип. Авторство и исходные материалы собраны в справке; нижний отступ оставлен только под навигацию.
